# 个人导航页 · 小功能模块策划案

> 文档类型：轻量功能模块策划（参考用）
> 适用项目：`flygeon` 个人导航起始页（Svelte 5 + Vite SPA）
> 版本：v1.1 ｜ 最后更新：2026-07-12
> 用途：规划一组**相互独立、可单独上线**的小功能页面（类「图片格式转换」「赞赏支持」），作为后续逐个开发的参考。

---

## 1. 功能概述

### 1.1 这是什么
一组**轻量小工具 / 小页面**，每个都是一个自包含的单页模块，挂在导航页下，通过顶部工具区或独立路由访问。它们：
- **彼此独立**：新增一个不影响其他，删掉一个也不破坏整体；
- **纯前端**：用浏览器原生 API（Canvas、File、Clipboard、Crypto 等）实现，无后端；
- **风格统一**：复用现有玻璃拟态卡片（`rgba(26,26,26,.55)` + `blur(16px)`）、胶囊按钮、`fadeUp` 入场、Font Awesome 图标；
- **落地范式一致**：每个模块 = 一个 Svelte 组件 + 一条路由 + 一处工具区入口（可选）+ 可选的数据配置文件。

### 1.2 与已上线模块的关系
| 已上线 | 路由 | 说明 |
|--------|------|------|
| 图片格式转换 | `/convert/` | 上传/粘贴 → 选格式 → Canvas 转 PNG/JPG/WebP → 下载 |
| 赞赏支持 | `/sponsors/` | 收款码展示 + 捐赠名单（数据在 `sponsors.js`） |

本策划案在其基础上，规划**下一批**同类小模块，并沉淀统一落地范式。

### 1.3 设计原则
| 原则 | 说明 |
|------|------|
| 单点可用 | 每个模块打开即用，不求大求全 |
| 零依赖 | 优先浏览器原生 API，不引重型库 |
| 视觉同源 | 严格沿用既有卡片/按钮/动画规范 |
| 可插拔 | 新增模块 = 加文件 + 注册路由 + （可选）加入口 |

## 2. 功能详细说明

> 每项含：**功能名称 · 路由 · 用途 · 交互方式 · 技术/数据 · 优先级**。
> 状态标记：✅ 已上线 ｜ ⬜ 待开发。

---

### M-01 图片格式转换  ✅ 已上线
- **路由**：`/convert/`
- **用途**：本地图片在 PNG / JPG / WebP 间互转。
- **交互**：上传/拖拽/`Ctrl+V` 粘贴 → 选目标格式（有损格式给质量滑块）→ 点「开始转换」→ 预览 + 下载。
- **技术**：`Canvas.toBlob`，JPG 填白底防透明变黑；数据全在组件内，无配置文件。

### M-02 赞赏支持  ✅ 已上线
- **路由**：`/sponsors/`
- **用途**：展示收款码 + 捐赠名单。
- **交互**：上下等宽双卡片，名单逐条 fly 入场；赠言为空则不显示。
- **技术/数据**：收款码路径与名单抽离到 `src/data/sponsors.js`，改文件即更新，无需动组件。

---

### M-03 二维码生成器  ⬜
- **路由**：`/qr/`
- **用途**：把文本 / 网址生成可下载的二维码。
- **交互**：输入框实时预览 → 选尺寸/容错等级 → 点「下载 PNG」。
- **技术/数据**：纯前端二维码库（轻量，如 `qrcode` 生成到 Canvas 后导出）；无持久化数据，组件内状态即可。

### M-04 图片压缩  ⬜
- **路由**：`/compress/`
- **用途**：上传图片，按目标质量/尺寸压缩，减小体积。
- **交互**：拖拽/选择图片 → 调质量滑块 + 可选最大宽高 → 转换 → 显示「原大小 → 新大小 / 节省 X%」→ 下载。
- **技术/数据**：`Canvas` 重绘 + `toBlob(quality)`；复用 M-01 的质量滑块与体积对比 UI 范式。

### M-05 时间戳转换  ⬜
- **路由**：`/timestamp/`
- **用途**：Unix 时间戳 ↔ 可读日期互转，支持当前时间一键填入。
- **交互**：输入时间戳（秒/毫秒自动识别）或日期 → 实时双向转换 → 点「复制」结果。
- **技术/数据**：`Date` 原生 API；纯计算，无存储；可加「时区」小选项（扩展）。

### M-06 JSON 格式化 / 校验  ⬜
- **路由**：`/json/`
- **用途**：粘贴 JSON，一键格式化（美化）或压缩，并高亮报错位置。
- **交互**：左输入 / 右输出双栏 → 「格式化」「压缩」「复制」按钮；解析失败显示行号提示。
- **技术/数据**：`JSON.parse` + 缩进序列化；可接轻量语法高亮（扩展，避免重型依赖）。

### M-07 颜色工具（HEX/RGB 互转）  ⬜
- **路由**：`/color/`
- **用途**：颜色格式互转 + 取色板预览 + 一键复制。
- **交互**：输入 HEX 或 RGB → 实时互转并展示色块；"复制"各格式；可选「随机配色」。
- **技术/数据**：字符串解析 + CSS 变量预览；纯前端，无存储。

### M-08 Markdown 实时预览  ⬜
- **路由**：`/md/`
- **用途**：左侧写/贴 Markdown，右侧即时渲染。
- **交互**：编辑即预览；「复制 HTML」「下载 .md」；可切「编辑/分屏/预览」三态。
- **技术/数据**：轻量 Markdown 解析（如 `marked`），注意 XSS——仅本地自用可接受，但输出建议做基本转义。

### M-09 倒计时 / 纪念日  ⬜
- **路由**：`/countdown/`
- **用途**：设置目标日（生日、考试、发布），展示剩余天/时/分/秒。
- **交互**：表单填名称 + 日期 → 实时倒计时卡片；多条可并列（数据存 localStorage）。
- **技术/数据**：`localStorage` 持久化条目数组 `{ title, date }`；每秒 `setInterval` 刷新（卸载清理）。

### M-10 随机抽签 / 转盘  ⬜
- **路由**：`/lottery/`
- **用途**：输入若干选项，随机抽一个，用于决定吃什么/谁干活。
- **交互**：多行输入选项 → 「开始抽取」动画 → 高亮结果 → 「再抽一次」。
- **技术/数据**：数组随机索引；纯前端，可选把选项存 localStorage 方便复用。

### M-11 文本加解密（娱乐向）  ⬜
- **路由**：`/cipher/`
- **用途**：用口令对文本做对称加解密（如 AES-GCM 或 Base64 混淆），用于临时传小秘密。
- **交互**：输入文本 + 口令 → 「加密」得密文（可复制）；切到解密模式粘贴密文 + 口令还原。
- **技术/数据**：`Web Crypto API`（原生，无需库）；明确标注"非高安全场景"。

### 3.1 总览表
| 编号 | 模块 | 路由 | 优先级 | 状态 |
|------|------|------|--------|------|
| M-01 | 图片格式转换 | `/convert/` | —（已上线） | ✅ |
| M-02 | 赞赏支持 | `/sponsors/` | —（已上线） | ✅ |
| M-03 | 二维码生成器 | `/qr/` | **P0 核心** | ⬜ |
| M-04 | 图片压缩 | `/compress/` | **P0 核心** | ⬜ |
| M-05 | 时间戳转换 | `/timestamp/` | **P0 核心** | ⬜ |
| M-06 | JSON 格式化 | `/json/` | **P0 核心** | ⬜ |
| M-07 | 颜色工具 | `/color/` | **P2 扩展** | ⬜ |
| M-08 | Markdown 预览 | `/md/` | **P2 扩展** | ⬜ |
| M-09 | 倒计时 / 纪念日 | `/countdown/` | **P2 扩展** | ⬜ |
| M-10 | 随机抽签 | `/lottery/` | **P2 扩展** | ⬜ |
| M-11 | 文本加解密 | `/cipher/` | **P2 扩展** | ⬜ |

### 3.2 划分依据
- **核心（P0）**：高频刚需、实现简单、纯前端无存储，能快速批量产出，与已上线模块技术同构（Canvas / 字符串处理）。
- **扩展（P2）**：偏趣味或需轻量持久化（倒计时、抽签），或引入小依赖（Markdown 解析），按需排期。
- 注：本策划案刻意**不含**书签系统、云端同步、命令面板等"产品级"功能——那些属于另一份更大的规划，不在"小功能模块"范畴。

## 4. 技术实现要点（统一落地范式）

### 4.1 一个模块的标准骨架
以新增 `M-03 二维码生成器` 为例，落地只需 4 步：

1. **建组件** `src/components/QrGenerator.svelte`
   - `<script>` 用 `$props()` 接收 `onBack`；
   - 状态用 `$state`，派生用 `$derived`；
   - 顶部 `返回` 按钮 + 标题，沿用 `ImageConvert` 的 `.top-bar / .back-btn / .card` 样式；
   - 底部独立 `footer`（如 `© 2026 flygeon`）。
2. **（可选）抽数据** 若内容会变（如名单、配置项），建 `src/data/xxx.js` 导出常量，组件 `import`——参考 `sponsors.js`。纯计算类（时间戳、JSON）不需要。
3. **注册路由** 在 `App.svelte`：
   ```svelte
   {:else if route === '/qr'}
     <QrGenerator onBack={() => navigate('/')} />
   ```
   并在顶部 `import QrGenerator from './components/QrGenerator.svelte'`。
4. **加入口（可选）** 在 `ToolButtons.svelte` 的 `toolLinks` 加一项 `{ name:'二维码', icon:'fa-solid fa-qrcode', route:'/qr/' }`（走既有 `onInternalNavigate` → `history.pushState`）。

### 4.2 路由机制（沿用既有，勿改）
- `App.svelte` 的 `getRoute()` 以 `window.location.pathname` 为准，`/xxx/` 与 `/xxx` 等价；
- `navigate(path)` 用 `pushState` 无刷新跳转并 `scrollTo(0,0)`；
- `popstate` 监听保证浏览器前进/后退正常；
- `vite dev` / `vite preview` 下深链均回退到 `index.html`（已验证 200）。纯静态托管（如 GitHub Pages）深链需 SPA 重写或对应 `xxx/index.html` 副本。

### 4.3 样式规范（强制同源）
| 项 | 值 |
|----|----|
| 卡片底色 | `rgba(26, 26, 26, 0.55)` |
| 卡片边框 | `1px solid #2a2a2a` |
| 圆角 | `16px` |
| 毛玻璃 | `backdrop-filter: blur(16px)` |
| 主按钮 | 白底 `#fff` + 黑字 `#0a0a0a`，胶囊 `999px` |
| 过渡曲线 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 入场动画 | `@keyframes fadeUp`（translateY 24px → 0） |
| 图标 | Font Awesome（`<i class="fa-...">`) |
| 响应式断点 | `≤720px` 单列堆叠 |

### 4.4 常见技术选型
| 需求 | 推荐（纯前端） |
|------|----------------|
| 图片处理 | `Canvas` + `toBlob` / `toDataURL` |
| 文件下载 | 动态 `<a download>` + `URL.createObjectURL` |
| 剪贴板 | `navigator.clipboard.writeText` / `paste` 事件 |
| 字符串/格式互转 | 原生 `Date` / `JSON` / 正则 |
| 轻量持久化 | `localStorage`（如倒计时条目） |
| 加密 | `window.crypto.subtle`（Web Crypto，原生） |
| 二维码/Markdown | 轻量 npm 包（`qrcode` / `marked`），注意体积 |

### 4.5 质量基线
- 每个组件 `vite build` 零错误；
- 交互元素带 `aria-label`、可见焦点环；
- 动画尊重 `prefers-reduced-motion`；
- 移动端触摸目标 ≥44px，单列可读。
