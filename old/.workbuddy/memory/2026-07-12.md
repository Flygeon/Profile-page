## 新增图片格式转换模块 (/convert/)

- **新增组件** `src/components/ImageConvert.svelte`：

- **路由**：`App.svelte` 新增轻量 SPA 路由（基于 `window.location.pathname` + `popstate`），`/convert` 渲染 ImageConvert，其余路径保持原主页；`ToolButtons` 增加“图片转换”入口，经 `onInternalNavigate` 用 `history.pushState` 无刷新跳转（含浏览器前进/后退支持）

## 修复：随机抽签抽取时内容水平偏移 (22:22)
用户反馈抽签时结果内容在一开始会往右偏一点然后恢复居中。
- **根因**：`.stage` 是 `display: flex; justify-content: center`，内部 `{#if}` 在 stage-empty（`display:flex;flex-direction:column` 带图标+文本）与 rolling-text（纯文本 div）之间切换时，两个 DOM 子节点的 flex 布局结构不同，浏览器重新计算时产生瞬时的水平偏移。
- **修复**：在 `.stage` 内新增一个持久化的 `.stage-inner` 容器（`display:flex;align-items:center;justify-content:center;width:100%`），`{#if}` 三个状态都包在该容器内。这样 `.stage` 的 flex 子节点永远是同一个元素，DOM 交换不会触发布局重算，内容始终居中。
- `vite build` 零错误零警告通过。

## 二次修复：抖动仍存（用户反馈首版未修好）(22:25)
首版仅加 `.stage-inner` 包裹层未解决水平偏移，改为"消除全部可疑因素"：

- 让三态 `.result-pick` / `.rolling-text` / `.stage-empty` 全部 `width:100%; box-sizing:border-box; text-align:center`，`.stage-inner` 加 `text-align:center`。状态切换时内容宽度恒定，不再有水平重定位。
- `vite build` 零错误零警告通过。

## 三次修复：抽签水平偏移（终版 grid 稳定居中）(22:29)
二版（去 fly 改 fade + width:100%）用户反馈"偏移更大了"，故推翻重来。
- **分析**：`{#if}` 在三个状态间删除/插入 DOM 节点，父级 flex `justify-content:center` 会按新子节点宽度重新计算居中位置 → 产生水平位移；且 `fly` transform 也可能引入子像素水平偏移。去掉 fly 反而更大，说明根因是**节点插入/移除导致的居中上下文重算**，而非 transform。
- **终版修法**：放弃 `{#if}` 删除重建，改为三态**常驻同一个 CSS grid 单元格**（`grid-template:"stack"; place-items:center`），靠 `.stage-state` 的 `class:hidden` 切换可见性（CSS 用 `opacity/visibility` + `transition:opacity .2s`，纯透明度无 transform）。居中参考永远是同一个固定单元格，状态切换不再触发布局重算/位移。
- `.stage-inner` 改为 `display:grid`；`.stage-state` 共 `grid-area:stack; width:100%; text-align:center`；原 `.result-pick/.rolling-text/.stage-empty` 保留宽度/对齐。
- `vite build` 零错误零警告通过。本环境无浏览器，无法目视验证，请用户本地 `npm run dev` 打开 `/lottery/` 确认。
